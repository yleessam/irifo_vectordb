[1. 프로그램 목적]

■	프로그램 설명 : 이 프로그램은 긴 텍스트를 RecursiveCharacterTextSplitter 를 사용하여 지정된 크기의 청크로 나누어 처리할 수 있도록 한다. 각 청크에는 일정한 크기와 중복 부분이 설정되어, 텍스트 분석, 검색, 또는 자연어 처리 모델에서 효과적으로 사용할 수 있도록 한다.
■	프로그램 기본 환경 : Phyton 3.10.10  
■	사용 라이브러리 : RecursiveCharacterTextSplitter(langchain.text_splitter)
■	특이 사항 : 설명의 편이를 위해 아래 프로그램은 특정 기능 중심으로 간단히 개발함
           ( Ex> Chunking 영역 중심 설명)
■   주요 내용

문서 청킹 기법 중 많이 사용하는 순환 청킹( Recursive Chunking)을 구현해 보도록 한다.
문단을 기준으로 문서를 분리하되, 긴 문장의 경우 Chunk Size 기준으로 조각을 나누면서도 최대한 문맥을 유지하도록 한다.

1) 주의사항
   : 프로그램 예제는 문단을 기준으로 문서를 분리하되, 긴 문단의 경우 중복 없이 특정한 Size 를 기준으로 반복하면서 조각낸다.
   : 단, 문단으로 나누지 않고 단순히 청크 사이즈로만 나누면서 일부 중복을 하고 싶으면 아래와 같이 프로그램을 보정할 수 있다.
   
    text_splitter = RecursiveCharacterTextSplitter(
     chunk_size=256,    # Each chunk will have 256 tokens/characters
     chunk_overlap=20,   # Ensure there are 20 characters of overlap between chunks
	 separators=[""]    # Empty string separator to split purely by characters
    )
   

[ 2. 프로그램 소스 ]

'''
■	프로그램 기본 환경 : Phyton 3.10.10
■	사용 라이브러리 : RecursiveCharacterTextSplitter(langchain.text_splitter)
'''

# Import necessary libraries
from langchain.text_splitter import RecursiveCharacterTextSplitter

# Define the text to be chunked
#text = """Your long document or text goes here. This could be several paragraphs or pages of content."""

text = """
[OOO 경제=OOO 기자]수도권과 비수도권 주택사업경기전망이 상반된 모습을 보이고 있다. 주택사업자들은 수도권 주택경기가 전월 대비 나아질 것이라고 판단했고 
비수도권은 더 악화되리라 내다봤다.
주택산업연구원이 주택사업자를 대상으로 이달 주택사업경기전망지수를 전망한 결과 전국 지수는 전월대비 4.6포인트(p) 하락한 81.6으로 나타났다.수도권은 1.3p 
상승한 107.4로 전망됐고, 비수도권은 전반적으로 하락세를 보이며 5.9p 하락한 76.0으로 전망됐다. 주택사업경기전망지수는 기준선인 100을 넘으면 주택사업 경기가 
좋아질 것으로 보는 업체의 비율이 높다는 것을 뜻하고 100을 밑돌면 그 반대를 의미한다.

수도권 가운데 경기는 전국에서 가장 큰 상승폭을 보이며 8.0p 상승(102.5→110.5)했고, 인천은 세달 연속 변동없이 기준선(100)을 유지한 반면, 
서울은 4.0p 하락해 111.9로 전망됐다. 수요에 비해 공급 부족 현상이 지속되는 가운데 서울과 그 인접지역의 아파트 가격은 여전히 상승세를 보이고 있으며, 
미국발 금리인하에 대한 기대감 등이 사업자 심리에 긍정적인 영향을 준 것으로 풀이된다.
비수도권의 경우 5.9p 하락한 76.0으로 전망됐는데 광역시지역은 모두 하락해 평균 8.9p(87.7→78.8) 하락했고, 도지역은 평균 3.6p(77.6→74.0) 하락했다. 
스트레스 DSR 2단계 규제 등 대출 강화와 주담대 금리 인상 등이 시장에 추가적인 부담으로 작용할 가능성이 높아졌고, 비수도권의 주택가격 회복세도 더딤에 따라 
사업자들의 심리에 부정적인 영향을 준 것으로 해석된다.

광역시권은 모두 하락했는데, 대전이 17.7p(100.0→82.3)로 가장 큰 하락폭을 나타냈다. 이어 대구 17.6p(95.8→78.2), 광주 11.1p(66.6→55.5), 
부산 4.9p(80.9→76.0), 울산 1.9p(89.4→87.5), 세종 0.4p(93.7→93.3) 순이었다. 도지역은 경남 6.7p(66.6→73.3), 경북 5.2p(73.3→78.5), 
충남 4.6p(80.0→84..6)을 제외하고 모두 하락했다. 강원 20.0p(100.0→80.0), 충북 12.7p(72.7→60.0), 전북 6.4p(83.3→76.9), 
제주 4.2p(76.4→72.2), 전남 2.1p(68.7→66.6) 순으로 내렸다. 대전은 지역 경제 침체와 아울러 지역 내 주택시장 침체가 장기화되면서 지수가 하락한 것으로 보인다. 

"""

# Create a character-based text splitter with a fixed chunk size
text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=256,    # Each chunk will have 256 tokens/characters
    chunk_overlap=0   # Ensure there are 0 characters of overlap between chunks
)

# Split the text into chunks
docs = text_splitter.create_documents([text])

# Display the results
for i, doc in enumerate(docs):
    print(f"Chunk {i+1}:")
    print(doc)
    print("\n" + "-"*80 + "\n")
